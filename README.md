# historical-epidemic-geospatial-analysis
Historical Geospatial Analysis of Epidemic and Environmental Patterns in Rangpur District (1891–1908)

# Project Description
This project conducts a historical geospatial analysis of epidemic outbreaks and environmental conditions in Rangpur District between 1891 and 1908. By digitizing colonial-era disease and mortality records—focusing on malaria, fever, and cholera—and integrating them with modern satellite raster datasets (NDWI, NDVI, and DEM), the study explores contemporary environmental characteristics around historically affected locations using Python-based spatial statistics.

# Key Highlights
Historical Data Compilation: Compiled and processed sixteen colonial-era disease and mortality records covering malaria, fever, cholera, and historical environmental observations in Rangpur District.

Geospatial & Raster Integration: Linked historical locality coordinates with modern NDWI (water), NDVI (vegetation), and DEM (elevation) raster datasets to examine present-day environmental patterns.

Spatial Statistics & Visualization: Executed 1 km buffer-based raster extraction, district-level spatial statistics, percentile analysis, and geospatial mapping using Python.

# Technologies Used
Programming Language: Python
Geospatial & Raster Processing: GeoPandas, Rasterio, Shapely
Data Analysis & Visualization: Pandas, NumPy, Matplotlib
Development Environment: Google Colab
